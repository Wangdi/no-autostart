# NoAutoStart - Design Document

Windows后台自启动进程管理工具

## 一、项目概述

### 1.1 项目名称
NoAutoStart

### 1.2 项目定位
Windows系统托盘应用，用于管理、关闭和永久禁用后台自启动进程。

### 1.3 技术栈
- **后端**: Tauri (Rust)
- **前端**: Vue 3 + TypeScript
- **构建工具**: Vite
- **状态管理**: Pinia

### 1.4 核心功能
1. 列出所有运行进程，展示详细信息
2. 本地知识库提供进程说明
3. AI网页跳转查询进程详情
4. 关闭进程（支持撤销）
5. 永久关闭自启动项
6. 维护自动关闭列表
7. 开机自动执行关闭

### 2.1 核心模块

| 模块 | 职责 |
|------|------|
| ProcessManager | 获取所有运行进程、进程详情、终止进程 |
| ConfigManager | 管理自动关闭列表、用户设置 |
| AutoCloseManager | 执行自动关闭逻辑、定时检查 |
| StartupManager | 管理/修改启动项（注册表、任务计划、服务） |
| HistoryManager | 操作历史记录、撤销操作 |

## 三、数据结构

### 3.1 进程信息 (ProcessInfo)

```typescript
interface ProcessInfo {
  // 基本信息
  pid: number;                    // 进程ID
  name: string;                   // 进程名
  executablePath: string;         // 可执行文件路径
  publisher?: string;             // 发布者/签名信息

  // 运行状态
  cpuUsage: number;               // CPU使用率 %
  memoryUsage: number;            // 内存使用 MB
  runningTime: number;            // 运行时长 秒

  // 启动来源
  startupType: StartupType;       // 启动类型
  startupLocation?: string;       // 启动位置

  // 本地知识库信息
  localDescription?: string;      // 本地描述
  isKnownProcess: boolean;        // 是否已知进程
  riskLevel: RiskLevel;           // 风险等级
  performanceImpact?: string;     // 性能影响说明
  recommendation?: string;        // 推荐建议

  // 推荐操作
  canClose: boolean;              // 是否可安全关闭
  recommendedAction: RecommendedAction;
}

enum StartupType {
  Unknown = 'unknown',
  RegistryRun = 'registry_run',           // HKLM/HKCU Run
  RegistryRunOnce = 'registry_run_once',  // RunOnce
  TaskScheduler = 'task_scheduler',       // 任务计划程序
  WindowsService = 'windows_service',     // Windows服务
  StartupFolder = 'startup_folder',       // 启动文件夹
  Normal = 'normal'                       // 普通用户启动
}

enum RiskLevel {
  Safe = 'safe',          // 安全，可关闭
  Caution = 'caution',    // 谨慎，可能影响功能
  Warning = 'warning',    // 警告，系统关键进程
  Unknown = 'unknown'     // 未知
}

enum RecommendedAction {
  None = 'none',              // 无需操作
  CanClose = 'can_close',     // 可关闭
  ShouldClose = 'should_close', // 建议关闭
  KeepRunning = 'keep_running' // 建议保留
}
```

### 3.2 自动关闭配置 (AutoCloseConfig)

```typescript
interface AutoCloseConfig {
  version: string;
  lastUpdated: string;

  // 自动关闭列表
  autoCloseList: AutoCloseItem[];

  // 设置
  settings: {
    autoRunOnLogin: boolean;      // 开机自启
    autoCloseOnStart: boolean;    // 启动时自动执行关闭
    checkInterval: number;        // 检查间隔(秒)，0=不轮询
    showNotification: boolean;    // 显示通知
  };
}

interface AutoCloseItem {
  id: string;                     // 唯一ID
  processName: string;            // 进程名
  executablePath: string;         // 可执行路径
  addedAt: string;                // 添加时间
  permanentAction?: PermanentAction; // 永久关闭操作记录
}

interface PermanentAction {
  type: 'disable_startup' | 'delete_task' | 'uninstall';
  description: string;            // 操作描述
  executedAt: string;             // 执行时间
  originalLocation?: string;      // 原始位置（用于恢复）
}
```

### 3.3 本地知识库 (ProcessKnowledge)

```typescript
interface ProcessKnowledge {
  processes: ProcessKnowledgeItem[];
}

interface ProcessKnowledgeItem {
  processName: string;            // 进程名（支持通配符）
  publisher?: string;             // 发布者
  description: string;            // 中文描述
  function: string;               // 功能说明
  startupMethod: string;          // 启动方式说明
  performanceImpact: string;      // 性能影响
  canClose: boolean;              // 是否可关闭
  recommendation: string;         // 推荐建议
  riskLevel: RiskLevel;
  tags: string[];                 // 标签（如：系统、第三方、驱动）
}
```

### 3.4 操作历史记录 (OperationHistory)

```typescript
interface OperationHistory {
  records: HistoryRecord[];
}

interface HistoryRecord {
  id: string;
  timestamp: string;

  // 操作类型
  operationType: 'close_process' | 'permanent_close';

  // 进程信息快照
  processSnapshot: {
    pid: number;
    name: string;
    executablePath: string;
    startupType: StartupType;
    startupLocation?: string;
  };

  // 永久关闭的额外信息
  permanentAction?: {
    type: 'disable_startup' | 'delete_task';
    backupData: any;  // 用于恢复的备份数据
  };

  // 状态
  status: 'completed' | 'reverted';
  revertedAt?: string;
}
```

## 七、技术要点

### 7.1 Windows API 使用

| 功能 | Windows API |
|------|-------------|
| 枚举进程 | CreateToolhelp32Snapshot, Process32First/Next |
| 终止进程 | OpenProcess, TerminateProcess |
| 获取进程路径 | QueryFullProcessImageName |
| 获取CPU/内存 | GetProcessTimes, GetProcessMemoryInfo |
| 数字签名 | WinVerifyTrust |

### 7.2 启动项检测位置

| 类型 | 位置 |
|------|------|
| 注册表 Run | HKLM/HKCU\Software\Microsoft\Windows\CurrentVersion\Run |
| 注册表 RunOnce | HKLM/HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce |
| 任务计划 | Task Scheduler API |
| Windows服务 | Service Control Manager API |
| 启动文件夹 | %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup |

### 7.3 AI查询链接

| 服务 | URL模板 |
|------|---------|
| Bing | `https://www.bing.com/search?q={processName}+进程` |
| ChatGPT | `https://chat.openai.com/?q={processName}进程是什么` |
| Claude | `https://claude.ai/new?q={processName}进程是什么` |
| Copilot | `https://copilot.microsoft.com/?q={processName}进程是什么` |
